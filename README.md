# 冥府祝福指南

幫助《Hades》玩家依**冥府兵器**與**型態**，規劃奧林帕斯神恩，並追蹤可達成的**雙重神恩**。

資料整理自：
- [Infernal Arms](https://hades.fandom.com/wiki/Infernal_Arms)
- [Boons](https://hades.fandom.com/wiki/Boons)
- [Duo Boons](https://hades.fandom.com/wiki/Duo_Boons)

非官方粉絲工具。Hades © SuperGiant Games。

## 使用方式

用瀏覽器直接開啟 `index.html`，或在專案目錄執行：

```bash
python3 -m http.server 8080
```

然後打開 http://localhost:8080

## 功能

1. **軍械庫**：選擇六把煉獄兵器，再選四種型態（含隱藏型態解鎖提示）。
2. **神恩規劃**：依型態顯示建議神、核心欄位與優先順序。勾選本輪已拿到的神恩後，右側會即時計算 28 道雙重神恩與 11 道傳說神恩的進度。點開卡片可看到還缺哪些前置，並可一鍵跳到該神恩。互斥的雙重會標示「不能同時擁有」；拿下一道後可標記已拿到，對方會改為無法使用。
3. **雙重神恩圖鑑**：可依一或兩位神篩選組合、前置條件與型態不相容提示。
4. **本輪系統**：夜之鏡（煉獄／冥河靈魂）、信物路線、此兵器較常用的代達羅斯鍛鎚。煉獄靈魂才能使用避雷針、滿載、更大召回與退出傷口；冥河靈魂才能使用自動裝填與壞消息。切換靈魂會自動取消不相容神恩。奧林帕斯信物會標示對應的神。信物與鍛鎚為規劃用精簡清單。這些選擇會寫進分享連結（例如 `&soul=stygian&k=owl-pendant`）。

攻擊／特殊／詠唱／衝刺／神援為互斥欄位，勾選新的會自動替換舊的。勾選狀態會存在瀏覽器，並寫進網址（例如 `#planner/stygius/arthur?b=heartbreak-strike,divine-dash`）。點「分享配裝」可複製連結；手機可直接系統分享。重新整理或把連結傳給別人，都會回到同一套武器、型態與神恩。

窄螢幕會預設開啟 **本輪模式**：上方五個欄位、中間快速勾選、底部固定雙重進度，方便邊打邊看。桌面版可點右上角「本輪模式」切換。

字型會先用系統字體顯示，再非同步載入網頁字型。若系統開啟「減少動態效果」、省流量模式、本輪模式，或分頁在背景，火星動畫會停止。勾選神恩時只更新欄位與雙重進度，不會整頁重繪。
